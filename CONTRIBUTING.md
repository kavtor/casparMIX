# Contributing

Use issue → branch → pull request → reviewed merge. Search existing issues,
choose a bug or feature template, and wait for a maintainer to mark the issue
`status:approved`. Every PR links that issue with `Closes #N`, has exactly one
`type:*` label, and must pass CI before merge. Keep commits conventional and
branches focused. English is the primary language for code, UI and documentation.

Do not commit credentials, personal configuration, media, ROM dumps or copied
proprietary manuals. Contributions are licensed under the project GPLv3 license.
Describe tests and their limits; do not equate simulation with hardware validation.
Program-output changes must be explicit operator actions, not hidden side effects.
